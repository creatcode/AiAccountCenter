# 功能、区域与运行模式矩阵

日期：2026-10-13。本文是目标范围与源码依据，所有 AiAccountCenter 产品能力当前均未实现/未验收。

标记：“复用”表示主仓库存在可继承实现；“扩展”表示需要新增或适配；“条件”表示需实际协议/客户端能力探测；“不提供”是本次明确边界。复用不等于已完成。

## 2. 运行模式

| 能力 | Windows 桌面 | Windows Web | Linux Web |
| --- | --- | --- | --- |
| 账号管理、备注、分组、导入导出 | 提供 | 提供 | 提供 |
| 平台支持的 OAuth/设备授权/凭据导入 | 提供 | 远程流程须核对 | 远程流程须核对 |
| 刷新、额度、官方用量、平台每日任务 | 提供 | 提供 | 提供 |
| 国际每日活跃的远端技术会话 | 提供 | 提供 | 提供 |
| 批量任务、后台计划、站内通知、Webhook | 提供 | 提供 | 提供 |
| 真实本机客户端发现/切换/启动 | 提供 | 不提供 | 不提供 |
| 用户会话列表/复制/关联/同步 | 按客户端条件提供 | 不提供 | 不提供 |
| 本地 IDE/CLI Token 统计 | 按来源提供 | 不提供 | 不提供 |
| CLI 配置、安装辅助、自动轮换 | 提供 | 不提供 | 不提供 |
| Hook 安装、Companion、托盘、桌面通知 | 提供 | 不提供 | 不提供 |
| 原生窗口、桌面开机启动、桌面更新 | 提供 | 不提供 | 不提供 |
| Rust 服务进程的部署/升级 | 可选独立服务 | 提供 | 提供 |

Web 服务操作的是服务器自己的账号库，不能读取访问者的本机客户端文件。Windows Web 也不因服务器系统是 Windows 而开放桌面接口。

不支持的接口必须在后端拒绝；前端不显示入口。直接请求、内部调用和调度器都要遵守同一能力边界。Linux 不允许自动安装 Hook 或触发本地客户端扫描。

Windows 桌面首版以 Windows 10/11 x64 为目标，安装包分别覆盖在线/离线 Runtime 准备；便携目录需要可用正式 WebView2，创建窗口前检查并提供原生修复提示。具体最低系统 build/Runtime 版本和兼容证据以 DEPLOYMENT.md、ACCEPTANCE.md 的冻结记录为准。独立 Windows/Linux Web 服务无需 WebView2。

## 4. Companion 来源与含义

- 核对来源：Codex、WorkBuddy 国内/国际、CodeBuddy IDE/VS Code、Codeg，按固定主仓库实际支持实现。
- 监听来源不代表新增其账号管理平台。
- Codex/WorkBuddy 等 Hook 与 Codeg 本机 Web Service 的接入方式分开处理。
- 安装成功、来源在线、收到有效事件、状态过期和跳转可用分别显示。
- Hook 配置修改须用户选择；保留其他 Hook/接收器与全局过滤设置，失败恢复。
- 发行版不得暗中要求安装 Python 才能执行 Hook；按实际依赖链补 Rust 随包入口。

## 5. 任务结果口径

| 状态 | 允许显示的证据 |
| --- | --- |
| 成功 | 取得该任务定义的服务端完成/领取结果 |
| 已完成，跳过 | 服务端状态明确当天/该活动已完成 |
| 待核查 | 请求可能已生效但响应未知，保存远端 ID/检查点 |
| 失败 | 明确业务失败、不可恢复错误或有限核查后失败 |
| 不支持/未开放 | 平台、区域、凭据用途或活动条件不满足 |
| 未接入数据 | 无本地/官方来源，不解释为零用量 |

国际技术会话 completed 和奖励到账分开记录。手动按钮、演示页面、HTTP 200、收到流式片段都不是自动任务完成证据。
