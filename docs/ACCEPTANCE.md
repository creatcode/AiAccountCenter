# 分层测试与交付验收

日期：2026-10-13。当前未运行任何 AiAccountCenter 产品测试。本文件是验收清单，不是通过报告。

## 1. 证据分级

| 类型 | 能证明什么 | 不能证明什么 |
| --- | --- | --- |
| 静态核对 | 源码、版本、许可、依赖与预期控制流 | 程序在真实系统/平台能工作 |
| 合成测试 | 解析、状态机、并发、异常与回滚 | 真实账号接口、客户端格式和奖励有效 |
| 隔离本机运行 | 本机程序、页面、原生行为与路径 | Linux/干净机器/真实账号均已通过 |
| 真实集成 | 明确授权范围内的真实业务结果 | 未测试平台、区域、版本或操作 |
| 部署/发行验证 | 指定系统和产物的安装、运行、恢复 | 所有架构/发行版/未来版本均兼容 |

记录提交、环境、命令或步骤、数据来源、预期/实际、通过/失败/待验收和证据位置。证据日志不含真实凭据或私人会话正文。

## 3. 必要异常矩阵

| 领域 | 必测情况 | 正确结果 |
| --- | --- | --- |
| 身份/区域 | 相同 UID 不同平台，CN/国际错配，未知客户端 | 拒绝串号与错误 endpoint，不写错客户端 |
| 登录 | state/nonce 不匹配、取消、过期、远程回调不可达 | 失败可解释，不入有效账号，不循环重试 |
| 凭据 | 错误密钥、密文移位、未知加密信封、PAT 误用 | 校验失败，不发空 Bearer，不转成 IDE 登录 |
| 刷新 | 两个刷新与重新授权交错、401 与业务“过期” | 旧结果不覆盖新凭据，不误刷新活动错误 |
| 管理面 | 未登录、过期会话、跨站、暴力登录、首次初始化抢占 | 有效拒绝与限速，敏感 API 不绕过 |
| 运行权限 | Windows Web/Linux Web 直接请求桌面路由 | 全部拒绝，调度与内部入口亦无副作用 |
| 路径 | ../、绝对路径、符号链接/重解析点、ZIP 路径逃逸 | 拒绝越界，不访问真实 home |
| 数据 | 损坏 JSON/SQLite、重复导入、磁盘满、迁移中断 | 明确错误，事务回滚，不静默变空账号库 |
| 每日任务 | 手动/批量/计划同时触发、跨日期/时区/活动 | 同一业务键只执行一次，状态可追踪 |
| 结果未知 | 领奖或创建会话后超时、远端完成本地未提交 | 保留检查点，先查询结果，不盲目重发 |
| 国际任务 | 只创建会话、首段 SSE、failed、completed 未确认奖励 | 不误报奖励成功，错误/待核查有证据 |
| 进程恢复 | 两实例启动、租约过期、任务中崩溃、重启 | 单执行者，接管先核查，不重复领奖 |
| 时钟/休眠 | 休眠后恢复、向前/后调时、计划窗口错过 | 有界补查，不集中重复执行 |
| 通知 | HTTP 超时、重定向、内网/元数据地址、重复事件 | 目标校验、有限重试、去重，任务结果不变 |
| 客户端切换 | 正在运行、正常退出失败、写到一半、身份不符 | 不默认强杀，备份恢复，未核验不报成功 |
| 会话 | ID 冲突、双方追加、顺序变化、附件缺失、中断恢复 | 源不变，索引一致，分歧阻止覆盖，可恢复 |
| Hook | 已有第三方配置、安装中断、外部修改后停用 | 不覆盖第三方内容，不盲目恢复旧全局配置 |
| Companion | 没事件、事件过期、伪造事件、非法 URI | 状态区分、认证/大小限制、受控跳转 |
| 统计 | 无数据、部分来源失败、不同计量口径 | 明确未接入/部分失败，不误记零或混算 |
| 更新/备份 | 错签名、错误密码、恢复到新目录、schema 回滚 | 拒绝不可信包，现库不受损，恢复实际可用 |

## 4. 构建与依赖

前端先生成 dist/ 再构建 RustEmbed。Windows desktop、Windows server、Linux server 分项验证；不使用 cargo build --workspace 证明 Linux server 可无桌面运行。

按 UI_REQUIREMENTS.md 验证登录、账号、额度、任务、通知、会话、客户端、统计和设置之间的状态一致性。

桌面主窗口/托盘/悬浮窗必须实际运行验证：显示、移动、置顶、关闭、明确退出、多窗口焦点和更新退出。截图不能替代这些行为。

## 6. 真实平台与客户端验收

在获得对应授权和凭据后，以有限单账号步骤验证，不批量压测真实平台。Token 不进入命令行、截图或报告。

平台验收分别记录登录身份/区域、刷新后的可用性、额度口径、活动状态及任务结果。国际技术会话记录脱敏远端 ID/步骤与奖励状态，不保存完整聊天正文。

客户端验收先记录版本、真实数据布局和可恢复备份，再在明确授权下切换测试；源账号/会话不受损，目标启动身份正确，失败能恢复。

未提供真实客户端/平台权限时，状态只能是“合成通过，真实待验收”。

## 7. 部署验收

- Windows 10/11 x64 干净环境安装/运行，分别验证在线包、离线包与便携目录，完成下列 WebView2 矩阵；新 Rust 数据与旧 Python 产品及原工具隔离。
- Windows 独立 Web 无原生窗口也可运行；浏览器关闭后后台继续。
- Linux 没有图形会话、客户端和 D-Bus session bus，服务仍能启动、登录、执行已授权任务。
- 远程浏览器访问实际服务主机，API 不指向访问者 loopback；授权回调可达且安全。
- secret 权限错误应拒绝启动；不回退随机新密钥或明文。
- 重启、卷持久化、实例互斥、磁盘异常、退出宽限和任务恢复。
- Docker 构建、运行、非 root、卷、secret、健康检查与恢复分别记录；缺 Docker 不记通过。
- 自有更新源、签名验证、错误包拒绝、升级失败与数据恢复分别验收。

### 7.1 Windows/WebView2 兼容矩阵

| 条件 | 验收结果 |
| --- | --- |
| 已有满足最低版本的正式 Evergreen | 复用并正常启动；不重复安装、不降级 |
| 无 Runtime，仅安装 Edge 浏览器或仅有预览通道 | 不误认正式 Runtime；安装包正确补齐，便携运行原生提示 |
| 在线包遇到缺失/过低 Runtime | 告知依赖并按用户选择安装/升级，结束后复检版本与环境创建 |
| 全新无 Runtime、断网、使用离线包 | 从随包完整 x64 安装器完成安装并启动界面，不联网下载运行时 |
| 在线包下载被阻断、代理/证书错误 | 明确失败及离线修复路径，不关闭证书校验、不假报就绪 |
| 用户取消安装/拒绝提权、受限账户/组策略 | 安全退出或给明确修复提示，不循环提权、不改变账号数据 |
| 当前用户安装与机器安装、32/64 位登记视图 | 正确识别可用正式 Runtime，按真实账户验证，不只看单一路径 |
| Runtime 低于最低版本、安装器成功但仍不可用 | 主程序复检阻止进入业务；记录版本/来源与错误代码 |
| Runtime 被卸载/损坏、WebView 创建失败 | 显示不依赖 WebView 的原生对话框，不白屏/闪退，不启动任务或 Hook |
| profile 无写权限、路径含空格/中文、安装目录只读 | 使用独立可写用户 profile；权限失败可解释，不删库或默默换真实目录 |
| Windows 10/11 x64，不同 DPI、远程桌面/虚拟机 | 主窗口、托盘、悬浮窗可用；图形故障有诊断，不默认修改全局配置 |
| Runtime 版本升级、应用升级/回滚、用户重新启动 | 正常创建环境，保留账号及状态；不卸载共享 Runtime |
| 无 WebView2 的 Windows/Linux 独立 Web 服务 | 无桌面依赖启动并可用；桌面失败不自动开放服务端口 |

在经授权的干净机器/VM 上验证缺失、低版本与权限场景，不在当前开发机卸载或降级共享 WebView2 来制造故障。记录系统 build、账户权限、Runtime 来源/版本、产物 SHA、实际结果；没有相应环境的行保留待验收。
