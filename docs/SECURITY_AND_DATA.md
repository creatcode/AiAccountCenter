# 安全、数据与恢复约束

日期：2026-10-13。本文为实现与验收要求，尚无产品代码。目标为单管理员、单业务实例，不扩展多租户或分布式执行。

## 1. 信任边界

- 浏览器、上传文件、平台返回、客户端文件与 Hook 事件均为外部输入，校验结构、大小、身份、区域和路径。
- 管理登录只授权操作 AiAccountCenter，不自动授权修改真实客户端、执行平台任务或发送外部通知；产品中危险操作需明确对象与后果。
- Web 模式的管理员也不能调用桌面功能。运行模式权限不能被请求参数、代理头或上传路径覆盖。
- CLI/Hook 接收入口与管理 API 分开认证；随机接入凭据不可替代管理员密码。
- 平台 endpoint 来源固定能力配置，不允许用户输入任意 URL 后附加平台 Token。
- 保留 TLS 证书校验；OAuth/敏感请求不盲目跟随跨域重定向。

## 2. 最小持久结构

使用已有 rusqlite，表名可按现有模块合理调整，不要求先创建所有空表。

| 记录 | 最小语义 |
| --- | --- |
| schema_version | 迁移版本、执行时间与完整性 |
| accounts | 内部 ID、platform、region、uid、显示信息、启用状态、备注/分组 |
| credentials | 用途、密文、nonce、版本、有效期、刷新/授权状态 |
| credit_snapshots | 来源、采集时间、余额、积分包与到期口径 |
| client_bindings | 账号、客户端种类、已核实安装路径/版本与身份状态 |
| client_snapshots | 加密快照位置/摘要、所属账号、客户端与恢复状态 |
| schedules | 任务类型、账号范围、时区、时间窗口、启用与重试 |
| task_runs / task_steps | 唯一运行键、状态、租约、远端 ID、步骤检查点、脱敏错误 |
| notifications / deliveries | 事件来源、阅读状态、投递渠道、去重、重试与结果 |
| admin_sessions | 密码版本、会话哈希/有效期、撤销状态 |

唯一约束 platform + region + uid，不能将相同 UID 的不同平台/区域合并。凭据版本用于条件更新，不仅靠更新时间。

会话关联与副本数据优先沿用上游结构；源会话文件、客户端 SQLite 与 AiAccountCenter DB 是不同存储边界，不声称跨文件/远端原子事务。

## 3. 凭据加密

- AES-256-GCM；从系统安全随机源生成主密钥和每次唯一随机 nonce，不使用时间戳、账号 ID 或固定 nonce。
- AAD 绑定账号、平台、区域、凭据用途和格式版本；密文交换到其他记录时必须校验失败。
- 凭据按用途区分 access、refresh、PAT、job token、IDE 状态，不能因都叫 Token 而互换。
- Windows 主密钥用用户范围 DPAPI 保护，验证是否在正确用户/机器上下文；不能声称 DPAPI 文件复制到 Linux 即可解密。
- Linux 使用用户显式提供的 secret 文件，非 root 服务用户只读；限制 owner/权限，不能从镜像内置默认密钥，也不依赖 Secret Service/D-Bus。
- 主密钥丢失应给清晰恢复/重新授权提示，不回退明文存储或自动生成新密钥覆盖旧凭据。
- 上游已加密的客户端信封与 AiAccountCenter 自有存储加密分层处理；不把未知信封当明文 access token 发请求。

## 4. 账号与 JSON 迁移

上游 JSON 可以显式导入，新产品正式库以 SQLite 为真源。保留旧 load/save 的调用语义但改持久化边界，不长期双写两个账号库。

导入按顺序执行：大小/格式版本校验 → 解密/解析 → 逐账号身份与区域验证 → 重复预览 → 单事务写入 → 核对结果。离线无法完成平台身份验证时保存为“待验证”，不开放真实任务。

删除账号前停止对应新任务，检查运行中任务及快照/关联依赖。账号删除、任务引用与通知可见性有明确策略；不通过删除当前使用账号绕过活动客户端保护。

迁移先生成一致备份，事务内更新 schema；失败不提升版本，恢复原数据。禁止自动读取 ~/.wb-switch 或旧 Python AiAccountCenter 数据库。新 Rust 项目与旧项目目录同名不授权继承旧库、旧密钥或旧用户数据目录。

## 5. 管理登录和 Web 会话

- 首次初始化只允许受保护的引导流程：例如本机控制台一次性初始化码，短时有效、单次消费；不得在开放端口由第一个匿名访问者直接抢设密码。
- 密码使用成熟密码哈希（例如经验证的 Argon2id），参数版本化并设合理资源上限，不自制哈希。
- 管理会话保存随机高熵标识，服务端存哈希；Cookie 使用 HttpOnly、SameSite，HTTPS 下 Secure；不把会话放 URL/localStorage。
- 写操作同时验证会话与 CSRF/Origin；请求内容类型和 Origin 白名单明确，不启用任意来源带凭据 CORS。
- 登录有限速与连续失败退避；错误不泄露密码状态。修改密码可撤销既有会话；退出立即失效。
- 会话过期保留非敏感未保存表单，重新登录后不自动重放领奖、删除或客户端写入。
- 桌面通过 Tauri 的可信窗口/commands 权限及管理解锁控制敏感调用；不允许远程网页取得原生调用权限。
- 健康检查只返回存活/就绪和非敏感版本信息。诊断导出同样脱敏。
- 只信任配置的反向代理源，不根据任意 X-Forwarded-* 自动认定 HTTPS、客户端 IP 或管理员来源。

## 6. 单实例、刷新与任务占位

同一数据目录只允许一个业务执行实例；第二个桌面/服务进程应拒绝启动或只向已有实例提示，不同时运行任务。

SQLite 实例租约与任务占位使用事务和唯一约束。租约包含 owner、到期与心跳；过期接管须重新核查旧任务，不能仅凭心跳过期就认为远端请求未发生。进程内 Mutex 只作为补充。

同一账号的刷新、重新授权与任务读取受串行/版本控制。网络请求用旧凭据快照，返回后仅在保存版本仍匹配时提交；不覆盖新授权或更晚刷新。

任务唯一键包含账号、种类、平台业务日期/活动 ID。手动、批量、启动恢复、定时重试共享占位。时间按 UTC 持久化，业务日期按平台已确认规则计算；不能用服务器本地日期替代全部平台。

建议状态：

~~~text
queued → running → succeeded / skipped / failed / cancelled
                  ↘ needs_verification → query remote → terminal / bounded retry
~~~

请求发出、远端会话 ID、步骤完成分别落盘。进程可能在远端已生效但本地未提交时崩溃；恢复必须查已有活动/会话证据。没有可核查协议时显示待人工核查，不无限重发。

取消请求不保证远端副作用撤销；已经发出的任务仍需核查。通知投递与任务执行分离，通知失败不导致再次领奖。

## 7. 客户端、文件与会话

- 只允许已发现/绑定的客户端根目录及已核对文件白名单。
- 校验规范化路径、符号链接/Windows 重解析点、目录穿越、账号 UID、区域和版本；Web 上传不得接受任意服务端路径。
- SQLite 快照使用一致备份或安全的退出/检查点流程，不直接复制运行中的主库而忽略 WAL/SHM。
- Trae 多文件恢复保留同机绑定语义，不从另一机器拷贝 machineid/密钥来“重置设备”。
- 写入前记录可恢复快照和步骤；跨多个文件的恢复逐步验证，失败保留诊断，不宣称全局事务。
- 客户端运行时优先正常退出/等待，不默认强杀。启动后核验 UID，而不是仅看到进程或文件存在就成功。
- 会话复制源不变，目标 ID/索引一致；同步有共同基线，双方分歧时不给无提示覆盖。
- 原生 URI/文件打开限定允许的 scheme、客户端与参数，不接受任意 Shell 命令。

## 8. Hook、Companion 与日志

Hook 安装需要用户在桌面明确选择，显示目标路径、事件和恢复策略。合并已有配置并备份；停用仅移除本程序管理内容，第三方已改动时停止自动恢复。

Codeg 全局事件过滤和其他接收器不得被覆盖。配置安装、事件源在线、事件有效、过期和跳转能力独立记录。

日志不包含 access/refresh/PAT、密码、Cookie、设备敏感值、Webhook 密钥、完整会话内容。平台错误返回先脱敏再显示；Hook 输入只保存必要事件摘要，未知事件限大小并拒绝。

调试导出仅在明确操作下产生，密钥/凭据默认排除；文件路径与账号标识按诊断必要性控制。

## 9. Webhook 与外部请求

管理员配置的目标单独保存、敏感部分加密；仅 HTTPS 或明确允许的可信目标。校验解析后的目的地址、端口和每次重定向，阻止云元数据及未授权本机/内网访问。用户明确需要内网目标时采用精确允许规则，不放开所有私网。

投递记录包含事件 ID、目标 ID、次数、状态和脱敏错误。设置超时、大小限制、有限重试和去重；不把 Token 放查询参数，不把完整平台响应直接转发。

“测试通知”属于真实外部发送，需要用户明确触发和授权，不能在保存设置时自动发送。

## 10. 备份与升级

备份应从一致数据库快照、关联元数据、必要加密客户端快照生成，记录格式版本和来源应用版本。可移植导出用独立口令 KDF+AEAD 重新封装，避免把机器绑定 DPAPI 文件当跨平台备份。

导入口令/KDF 参数设上限，错误密码与损坏密文拒绝且不改当前库。按整批事务、重复策略和恢复点操作。

升级前保存旧二进制和可恢复数据，验证签名/摘要与 schema 兼容；新版本失败后恢复旧版需要匹配的数据版本。回滚不能只替换程序而保留旧版无法读取的新 schema。

密钥备份、口令遗忘与主密钥损失的限制必须写进用户说明，不承诺无凭据恢复解密。

### 10.1 WebView2 安装与数据边界

仅接受微软官方 Runtime/安装器，核对数字签名；下载保持 TLS 校验。正常程序启动不暗中安装、提权或修改全局运行时；安装包在用户同意所需组件后处理，失败和取消不触发账号任务或客户端操作。

WebView2 profile 使用新 Rust App ID 的独立可写用户目录，开发放 .runtime/。Runtime 创建失败不能默认删除 profile 或账号库，也不能改用旧 Python 数据目录。卸载本应用不卸载共享 Evergreen Runtime。固定版随包时将其版本和更新纳入应用发行维护。

## 11. 必须通过的安全验收

未登录/跨站/过期会话拒绝；Web 桌面接口拒绝；平台/区域/UID 错配拒绝；密文移位/错误密钥拒绝；导入超限/损坏回滚；旧刷新结果拒绝覆盖；重复任务/进程占位；副作用超时核查；路径逃逸/重解析点拒绝；日志无秘密；备份真实恢复。
